# ✈️ Sky_Blaster
A simple and responsive browser-based arcade game built with HTML, CSS, and JavaScript.


Control your aircraft, destroy enemy aircraft, earn points, and beat your high score.

![image alt](https://github.com/itsmeronie-20/Sky_Blaster/blob/866747b38c3b70c77f61082efe3f5c14504e3816/img/aircraft.png)

# 🎮 Features

- Enemy aircraft
- Shooting system
- Score and high score
- 3 lives
- Increasing difficulty
- Explosion effects
- Keyboard, mouse, and touch controls
- Mobile-friendly design
- High score saved with "localStorage"

# 🕹️ Controls

PC

- "W A S D" or "Arrow Keys" — Move
- "Space" — Shoot

Mouse

- Click and move to control the aircraft.

Mobile

- Touch and hold the screen to move and shoot.

# 🚀 How to Run

No installation is required.

1. Download or clone the repository.
2. Make sure all files are in the same folder.
3. Open "index.html" in your browser.
4. Click START GAME.

# 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Canvas API
- Local Storage API

# 🎯 How to Play

1. Start the game.
2. Move your aircraft.
3. Shoot the incoming enemies.
4. Earn 10 points for every enemy destroyed.
5. Avoid enemies and prevent them from escaping.
6. Keep playing until you lose all 3 lives.
7. Try to beat your best score.

# 📱 Responsive

Sky Blaster supports both desktop and mobile devices with keyboard, mouse, and touch controls.
